# 1. Theory
### I.1 Expected return
$$
\mathbb{E}(R_{t})=\frac{\mathbb{E}(P_{t+1})-P_{t}}{P_{t}}
$$

# 2. Interpretation
### I.1 SML
The **SML** is the linear function given by the **expected return**. Indeed, the x-axis represents the risk ([[β]]) and the y-axis the expected return. We can then compare a plot to the line :
	If the plot is below the line, it is overvaluated since the investor would accept the same risk for a lower return.
	If the plot is above the line, it is undervaluated because the investor can expect a greater return for the same risk.
### I.2 Asset pricing
Since the [[Capital Asset Pricing Model]]'s goal is to indicate the value of $\mathbb{E}(R)$, we can compare this calculation with the expected return at time $t$. If $\mathbb{E}(R_{t})\ge\mathbb{E}(R_{i})$ this could suggest that the price is too low and it is undervaluated (or overvaluated if $\mathbb{E}(R_{t})\le\mathbb{E}(R_{i})$).
