# Definition
## I. Statement

>[!hint] Definition
>Let $(M,*)$ be a **[[Magma|magma]]**. Any element $e\in M$ is said to be **left neutral** if
>$$
\forall m\in M,e*m=m
>$$
>It is **right neutral** if
>$$
\forall m\in M,m*e=m
>$$
>If such an element is both left and right **neutral**, it is called a **two-sided identity** or **identity**.
## II. Extensions
### 1. Properties

>[!tip] Idempotency
>>[!tldr] Property
>A **neutral element** is *idempotent*.
>
>>[!info] Proof
>>Let $(E,*)$ be a **[[Magma|magma]]**.
>>$$
\forall x\in E, e*x=x\wedge x*e=x\Longrightarrow e*e=e
>>$$
