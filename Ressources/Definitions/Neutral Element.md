# Definition
## I. Statement

>[!hint] Definition
>Let $(M,*)$ be a **[[Magma|magma]]**. Any element $e\in M$ is said to be **left neutral** if
>$$
\forall m\in M,e*m=m
>$$
>It is **right neutral** if
>$$
\forall m\in M,m*e=m
>$$
>If such an element is both left and right **neutral**, it is called a **two-sided identity** or **identity**.
