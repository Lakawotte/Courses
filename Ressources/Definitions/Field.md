# Definition
## I. Statement

>[!hint] Definition : **[[Ring]]**
>We call **field** an **[[Ring|abelian ring]]** where $0\neq 1$ and all nonzero elements are **[[Internal Binary Operation|invertible]]** under $\times$.
#### Note :
The condition $0\neq 1$ allows us to not consider $\{0\}$ as a **field**.

>[!tip] Definition : **Field** Axioms
>A **[[Set|set]]** $(F,+,\times)$ is a **field** if :
>1. It is *Associative*
>2. It is *Commutative*
>3. $+$ and $\times$ has **[[Neutral Element|neutral elements]]** $0_F$ and $1_F$
>4. $+$ and $\times$ are *[[Internal Binary Operation|symmetric]]*
>5. $\times$ is *[[Internal Binary Operation|distributive]]* over $+$

>[!tldr] Division **[[Ring]]**
>When a **[[Set|set]]** satisfies all the field axioms but *commutativity*, it is called a *division ring*.
