# Definition
## I. Statement

>[!tip] Definition
Let $A$ and $B$ be two **[[Power Set|subsets]]** of a finite **[[Set|set]]** $\mathcal{E}$. We call **intersection** of $A$ and $B$ the set made of elements from $\mathcal{E}$ which are both in $A$ and in $B$
>$$
A\cap B=\{e\in\mathcal{E},e\in A\vee e\in B\}
>$$
## II. Extensions
### 1. Properties

>[!tldr] Karnaugh Representation
>|           | $A$            | $\bar{A}$            |
| --------- | -------------- | -------------------- |
| $B$       | $A\cap B$      | $\bar{A}\cap B$      |
| $\bar{B}$ | $A\cap\bar{B}$ | $\bar{A}\cap\bar{B}$ |

>[!tldr] Morgan Rule
>$$
\bar{A\cup B}=\bar{A}\cap\bar{B}
>$$
