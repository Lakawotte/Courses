# Definition
## I. Statement

>[!hint] Definition
>Let $(G,*)$ and $(F,*)$ be two **[[Group|groups]]**. Any **[[Application|application]]** $f:G\to F$ is a **morphism** if
>$$
\forall(x,y)\in G^2, f(x*y)=f(x)*f(y)
>$$
## II. Extensions
### 1. Properties

>[!tldr] **[[Neutral Element]]**
>Let $(G,*)$ and $(F,*)$ be two **[[Group|groups]]** and $f:G\to F$ a **morphism** :
>$$
f(e_{G})=e_{H}
>$$

>[!tldr] Inverse
>Let $(G,*)$ and $(F,*)$ be two **[[Group|groups]]** and $f:G\to F$ a **morphism** :
>$$
\forall x\in G,f(x^{-1})=f(x)^{-1}
>$$

>[!tldr] Types of Morphism
>A **[[Group|group]]** **morphism** $f:G\to H$ is :
>- *surjective* if and only if $\mathrm{Im}(f)=H$
>- *injective* if and only if $\mathrm{ker}(f)=\{e_{G}\}$
>
>$f$ is an *isomorphism* if it is both *surjective* and *injective*.
