# Definition
## I. Statement

>[!hint] Definition
>Let $(G,*)$ and $(F,*)$ be two **[[Group|groups]]**. Any **[[Application|application]]** $f:G\to F$ is a **morphism** if and only if
>$$
\forall(x,y)\in G^2, f(x*y)=f(x)*f(y)
>$$
